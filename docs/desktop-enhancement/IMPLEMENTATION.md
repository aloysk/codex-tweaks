## 实施顺序

### 开发起点

确认仓库、分支、上游基线与现有改动，读取根 `AGENTS.md` 和 PRD 速读卡。按贡献指南运行适用的本地检查；共享 Go 和生成契约修改仍需双平台 CI。开发工具 bootstrap 不安装本产品，普通单元测试保留所有 live/integration 标志关闭。

一个 Go sidecar 继续拥有业务；WinUI/SwiftUI 只消费生成契约并负责平台呈现。完整设置放在独立 companion 面板；主题/壁纸实际应用到官方 renderer。不要为这轮目标建立通用状态机、服务端、插件市场或新的聊天壳。

### G1 目标身份、日常启动与恢复

**目标：** 连接明确的官方目标，保持用户工作，准确报告停用结果；把日常正常启动目标与当前 CDP 限制分开。

源码起点：`backend/internal/core/platform*.go`、`cdp.go`、`controller*.go`、`injection.go` 和相邻 tests；需要共享显示语义时修改 Go Presentation 源并生成两端产物。

1. 用路径、PID 和启动身份确认目标；覆盖无关同名进程、多实例、退出与 PID 重用。
2. 分别验证普通官方启动、已运行实例和增强启动。目标是 companion 伴随官方 App 或登录后台启动时不自行拉起 Codex、不弹出管理面板或抢焦点；用户显式打开控制面板时则显示或复用面板。目前继承行为不能按目标宣传。CDP 不存在时提供明确指引，不能静默重启或改官方二进制。
3. 收窄上游按进程名终止和自动强杀路径；取消、超时和身份不明时保留工作。
4. 汇总逐目标 cleanup 结果。继续注入已停止、页面清理已验证、CDP 监听已关闭分别核验，不以 WebSocket 断开推断后两者。
5. 合成进程/renderer 与 mock 先行，再在适当的空闲测试实例验证；需要用户保存任务并退出时不能让脚本代为确认。

**通过证据：** 无关进程和合成草稿不变；取消不终止工作；故意 cleanup 失败不报告恢复完成；用户普通重开后目标不带 CDP 参数且监听消失。无法通过普通启动接入时记录为预览限制。

**未通过：** 保持未连接或恢复待确认，不往日用窗口加载新包。

### G2 面板驱动官方外观

**目标：** 用户在 companion 调整一个主题/阅读布局，官方窗口出现实际效果并可恢复。

PR4 通过原生外观页、共享 Go 设置校验/持久化与已绑定 renderer 实现窄设置桥：面板命令 → Go 校验 → 目标/revision 绑定 → renderer 应用与实时验证 → 结果确认。外观能力不是通用 SDK 或新增包权限；只收到同一目标的实际成功确认才提交保存与“已应用”。

先完成原生/舒适布局、主题和纯色背景，再验证本地静态图片。Go 可以为用户主动选择的素材提供范围受限的保存/引用能力；包不因此默认获得 Node 或任意文件权限。上游 `custom-background` 整包声明 Node，只选本地模式不能免除该信任边界。持久化未通过时只交付明确标为本次有效的预览或已验证外观。

**通过证据：** 官方长会话、代码、差异和审批在浅/深色、100%/125%/150% DPI、窄窗和高对比度可读；配置和实际应用结果一致；取消/保存失败保留正确状态；20 轮启停无资源累积；图片不发外部请求。

**未通过：** 关闭失败能力，保留已验证主题/布局；不扩大通用权限掩盖缺口。

### PR4 实现与证据范围

- Go 拥有主题、布局、纯色/图片、遮罩、预览/保存/取消/恢复语义；SwiftUI 与 WinUI 使用生成 DTO 和同一动作/文案。保存失败保留可取消的预览，目标变化和停用清理自身资源。原生/薄荷/深色主题不改写官方主题节点、配置或二进制。
- Go 只读取用户显式选择的静态 PNG/JPEG/WebP，限制 5 MiB 和 4096 px，拒绝动画/伪装/截断文件；保存到独立素材目录并使用 opaque SHA-256 标识。存储最多 8 张/40 MiB，不驱逐素材，renderer 使用内联数据而不发图片外部请求。
- 非原生阅读布局尚无可信适配，舒适/紧凑选项禁用，伪造请求由 Go 拒绝。背景要求唯一正文容器、可见性与实时可读性验证；不明、遮挡或失配时回滚。系统高对比度关闭效果，减少动画偏好不产生过渡。
- 2026-10-03：隔离的官方 Windows `OpenAI.Codex_26.930.2377.0_x64` 空白窗口确认原生 → 薄荷 → 深色 → 原生基础色值及目标/revision 回传，清理后自有样式/标记为零。该窗口没有登录、会话或正文容器；结果只证明基础主题链路，不证明聊天背景或完整阅读兼容。
- 真实 headless Chromium 的 7 组/13 个合成场景验证图片解码、CSS/几何、普通文字/次级文字/图标对比度、代码/差异/审批颜色保留、媒体偏好、候选回滚、晚到取消、同 revision 的设置确认、20 轮启停及 40 次替换。焦点、草稿、选区与滚动保持，清理后自有样式、标记、监听和 observer 为零。这些场景不使用官方应用代码或真实会话。
- Windows 身份查询改用 AppModel/Toolhelp/进程启动时间/TCP owner 原生 API，保留 Store 来源、注册路径、父进程身份和监听归属验证；只读实测从约 5 秒降至 51–54 ms。合成测试覆盖路径逃逸、父 PID 重用、同名外部进程、IPv4/IPv6/通配监听与取消，不以名称推断身份。

完整 G2 仍待登录后长会话、官方背景、审批、100%/125%/150% DPI 和原生命令到首帧的性能验证；macOS 官方附加与安装/更新/卸载真机验收也未完成。CI、合成 Chromium 与空白官方窗口证据分别记录，PR4 合并不代表 P0 日用产品全部完成。本次任务不要求用户为验收登录，也不继续操作其官方工作窗口。

### G3 任务状态、速率与额度

**目标：** 每个指标有正确范围、来源、时间和精度，面板与胶囊消费同一 Go 快照。

额度研究起点为 `codex-tweaks-usage-overview@2cfbec5563b5e0eb46cd146574d8986a14cc5e45`，读取 active `rate-limit-status` Query Cache 并拒绝多 scope 歧义。任务和速率来源另行验证；不把这个额度适配当通用 API。参考索引见 [资源目录](../resources/README.md)。

- 当前选中任务必须有明确绑定，最近活跃日志只能叫最近观测活动；运行、完成、待审批各有对应证据和失效规则。
- token/s 需同回合输出 token 计数与有效生成区间；只有文本观测时可显示带“约”的字符/秒速率，不伪装 token/s。
- 额度按实际账户窗口表达；账户切换、歧义、缺字段和断连撤下对应旧值；读取时间不等于源更新时间。
- 不读写认证文件、不自动换号、不发 prompt 刷新，不假定独立 app-server 能观察官方当前会话。

**通过证据：** 合成 fixtures 覆盖身份变化、歧义、缺失、陈旧、计数器重置和采样不足；至少一个真实任务信号和真实有效额度样本与来源一致。精确速率未成立可以明确不可用，不阻断其他信号。

**未通过：** 下线对应数字并说明原因。只有合成数据时称视觉原型，没有真实任务信号和额度时不能称状态版完成。

### G4 Companion 与最小胶囊

**目标：** 完整原生控制面板和可选浮动胶囊提供连续体验，官方 App 始终是主工作窗口。

面板提供概览、外观、增强和设置导航，使用现有后端客户端。胶囊默认关闭；开启后先做固定可拖动位置、收起/隐藏、返回同一面板和无激活更新。后续通过身份验证才加入窗口跟随；桌宠另列后续功能。官方侧栏按钮与私有设置导航不再是首版依赖。

**通过证据：** 空/多行草稿、中文 IME、键盘、审批、长会话和不同窗口不丢内容或误发；100 次被动更新不抢焦点；显示器拔出或 DPI 改变后控件可达；高对比度与减少动画可用。执行 PRD 五个验收剧本和同机性能比较，来源失效在面板与胶囊同步体现。

**未通过：** 关闭失败的胶囊或快捷能力，保留可达面板与恢复；不通过重载/重启掩盖输入问题。

## 首个可安装版本的交付条件

G1–G4 的开发验证之外，还需要：

- 隔离 fork 的应用/package ID、更新源、数据目录、签名/品牌和卸载归属；验证既定并装策略，不自动迁移上游状态。
- Windows x64 真机验证安装、升级、卸载与重新启动后的恢复；ARM64 和 macOS 按对应真机声明支持，交叉构建只证明产物架构。
- 共享 Go 与生成契约满足双端要求；当前支持和失配版本均有处理证据。
- 发布物只含代码、必要资源和有效许可；用户图片、商标与第三方素材按实际分发内容核实。
- 发布操作单独遵守实际授权和发行条件；文档/基础设施 PR、CI 构建和打包不自动授权发布或安装。

PR3 将安装/数据/缓存/包信任和更新身份改为本项目所有；发行更新保持关闭，直到自有签名与发行渠道完成验收。身份源码、合成 nupkg 校验与构建不能代替真实安装/升级/卸载，后者属于 PR6 的交付条件。G1 的合成检查通过后再安排实际运行验证。
